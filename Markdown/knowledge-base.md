## 产品一：个人精英健康Pro+测评系统

### 产品概述
- 产品名称：个人精英健康Pro+测评系统
- 组成：APP（个人健康Pro+）、PC端（个人健康精英）、后台管理系统
- 后台地址：http://management.lifetide.cn/login
- App下载中心：https://jkkeji.netlify.app/html/qrcode.html

### 系统架构
- Web后台（B/S）：基于浏览器访问，用于机构与设备管理
- 移动端App（C/S）：运行于Android，负责设备绑定、测评执行与数据上传
- PC客户端（C/S）：桌面应用（版本1.0.6），用于历史数据回放与深度分析
- 三端通过统一云服务进行数据同步

### 用户角色与权限
| 角色 | 权限说明 |
|------|---------|
| 系统管理员 | 创建一级机构、分配全局设备、管理所有子账号 |
| 机构管理员 | 管理本机构设备、查看本机构用户测评数据 |
| 管理师 | 通过ID被用户绑定，可查看所辖用户测评报告 |
| 终端用户 | 使用App绑定设备、执行测评、查看个人报告 |

### 五大测评项目

#### 1. 睡眠测评
- 设备：血氧戒指（可选）
- 开始前：发射器需充满电，手机连接充电器
- 操作：点击"开始睡眠测评"按钮
- 时长：≥8小时自动结束，或手动提前结束
- 报告条件：有效数据≥1小时 + 必须填写"睡眠自评"
- 注意：主机与手机距离需在3米内，超过30分钟自动结束
- 数据不足1小时不生成报告
- 睡眠中醒来或起夜，不需要点击"结束睡眠"

#### 2. 情绪测评
- 设备：心电/呼吸传感器
- 环境：需在安静隔音环境，需联网
- 时长：10分钟自动结束
- 报告条件：必须完整执行10分钟
- **禁止手动结束，否则无报告**
- 手动点击"结束测评"，不会有测评报告，也不会有测评记录

#### 3. 体能测评
- 设备：心电/呼吸传感器
- 方案设置：默认静息1分钟、运动3分钟（可自定义）
- 阶段：静息→运动→半程恢复→全程恢复
- 静息阶段：保持安静，禁说话、玩手机
- 运动阶段：按语音提示运动，不适立即停止
- 半程恢复：达到50%后可手动结束
- 全程恢复：自动结束测评
- 报告条件：全程恢复后自动结束，或半程后手动结束

#### 4. 健康测评
- 设备：血压计、血糖仪、血氧戒指、体温计（均可选）
- 时长：10分钟自动结束
- 报告条件：必须完整执行10分钟
- **禁止手动结束，否则无报告**
- 可在测评前点击"记录"输入其他时间测的血压、血糖、血氧、体温数据
- 测评过程中可点击"录屏"按钮录屏

#### 5. 导航测评
- 设备：心电/呼吸传感器 + 耳机（推荐）
- 环境：安静环境，仰卧姿势
- 时长：30分钟
- 开始条件：需检测到稳定的心电呼吸波形
- 报告条件：必须填写"导航自评"问卷
- 手机需调至静音模式
- 跟随"生命的潮汐声"进行深度放松

### 设备管理

#### 设备充电
- 睡眠测评前：必须充满电
- 其他测评：电量不低于30%
- 充电指示：红色=充电中，绿色=已充满
- 充电方式：橙色点一端与收纳盒凹槽内橙点位置对应放入收纳盒

#### 设备绑定（App端）
- 主设备：我的→添加设备→扫描设备二维码
- 配套设备：我的→添加配套设备→列表中点击绑定
- 血氧戒指：佩戴到手指自动开机，不佩戴2分钟后自动关机
- 血压计：长按电源键开机，3分钟无操作自动关机
- 体温计：安装电池后蓝灯闪烁等待连接
- 所有设备绑定后，再次使用时开机可自动连接

#### 佩戴设备
- 用酒精棉或卫生湿巾清洁胸骨柄（骨性结构）位置皮肤
- 男士如有胸毛，需剔除后再进行清洁处理
- 粘贴电极片，按压紧实
- 主机LOGO灯亮起=开机，自动连接成功后灯熄灭
- 佩戴时避免受到刮碰和挤压

#### 设备解绑与迁移
- 先在"设备录入"查询设备所在机构
- 在原机构点击"查看/解绑"
- 解绑后可重新分配到其他机构

### 后台管理

#### 机构管理
- 创建一级机构账号
- 支持逐级创建二、三级子机构
- 上级机构可管理下级机构

#### 设备分配
- 新设备：机构账号管理→设备添加
- 分配：设备管理→机构设备管理→分配设备→勾选设备移动
- 解绑：机构设备管理→查看/解绑→搜索设备→解除

#### 管理师管理
- 在机构账号下创建管理师
- 用户在App"我的"界面输入管理师ID绑定

### PC端功能
- 名称：个人健康精英PC
- 版本：1.0.6
- 功能：数据回放、子午流注分析、报告导出
- 筛选：姓名、手机号、设备号、数据类型、日期
- 支持鼠标拖动查看异常数据详情
- 支持同时查看多个用户数据

### 报告查看
- App端：报告标签页，支持按日/周/月/年趋势切换
- PC端：支持按姓名、手机号、设备号、数据类型、日期筛选
- 支持异常数据定位（鼠标拖选查看细节）
- 分享功能：点击右上角分享按钮，可截图发送分享
- 支持通过日历选择特定日期查看历史数据

### 异常数据处理
- 非正常结束的测评数据需在"我的→上传数据"中手动上传
- 上传成功后可在报告列表查看

### 常见问题（Pro+）

#### 没有生成报告
- 睡眠测评：检查是否≥1小时 + 是否填写睡眠自评
- 情绪/健康测评：是否完整执行10分钟（手动结束无报告）
- 导航测评：是否填写导航问卷

#### 设备连接不上
- 检查发射器电量是否充足
- 确认手机蓝牙已开启
- 将发射器从收纳盒取出，确保Logo灯亮起
- 尝试放回盒中再取出重启
- 或在手机蓝牙设置中忽略该设备后，回到App重新搜索绑定

#### 胸贴总是掉
- 用酒精棉片清洁皮肤，去除油脂
- 待皮肤完全干燥后再粘贴
- 男性用户建议先剔除胸毛
- 粘贴时确保两片电极与皮肤紧密贴合，中间不要有气泡

#### 血氧仪测不出数据
- 检查手指是否完全插入指夹底部，指甲面应朝上
- 手指过冷或涂有深色指甲油可能影响测量
- 建议搓热双手或去除指甲油后再试
- 测量时保持手部静止，等待几秒钟直到数值稳定

## 产品二：睡眠呼吸监测仪

### 产品概述
- 产品名称：睡眠呼吸监测仪（五人系统）
- 用途：面向医疗机构或健康管理机构的多用户睡眠呼吸障碍筛查与评估
- 支持最多5名用户并行使用
- 架构：端-边-云协同架构
- 适用场景：睡眠门诊、体检中心、康养机构

### 系统组成
| 组件 | 功能说明 |
|------|---------|
| 传感发射器（设备） | 集成心电、呼吸、体位传感器，实时采集生理信号 |
| 收纳盒与电极 | 用于设备存储、充电及信号采集 |
| 移动终端（App） | 用户端操作入口，负责设备连接、数据上传及查看报告 |
| 云服务器 | 用户认证、数据存储、AI分析、报告生成 |
| 多PC终端（BBS-LTSP软件） | 医生/健康管理师专用工具 |
| 专用电脑 | 预装BBS-LTSP软件，开箱即用 |

### 软件组成
- 睡眠呼吸监测仪PC端（BBS-LTSP软件）
- 睡眠呼吸监测仪APP
- 后台管理系统
- BBS传感发射器（白色盒子）
- 血氧戒指（选配）

### PC端软件（BBS-LTSP）功能

#### 登录认证
- 双击桌面快捷方式启动
- 输入用户名/密码登录（支持"记住密码"）
- 依赖网络环境：局域网≥100M，互联网≥10M

#### 用户管理
- 用户注册四步流程：
  1. 手机验证（短信验证码）
  2. 基本信息（姓名、性别、年龄等）
  3. 身体状况（身高、体重、病史等）
  4. 信息完善（紧急联系人等）
- 支持修改、删除用户信息
- 已删除用户可通过"右上角找回"恢复

#### 设备管理
- 子账号设备管理：预分配各子账号可使用的设备范围（安装时配置）
- 设备查询：查看设备使用状态（空闲/已绑定/异常）
- 设备异常时可直接提交报修

#### 睡眠管理
- 实时监测：查看当前正在监测用户的实时心电、呼吸、体位波形
  - 前提：用户PAD已联网且点击了App中的"开始睡眠"
- 历史查询：支持按姓名、手机号、设备号、日期模糊检索
- 支持多维度缩放、拖选、播放控制

#### 报告生成与导出
- 测评结束后，基于自评问卷+AI自动分析生成"双百分睡眠报告"
- 支持导出PDF格式报告
- 报告包含客观指标与主观评分

### App端功能
- 首次使用：输入PC端已绑定的设备号完成配对
- 连接成功：界面显示稳定心电图
- 开始睡眠：点击【开始睡眠】按钮启动监测
- 扩展设备：支持扫描连接血氧戒指
- 报告查看：在【菜单>个人报告】中查看
- 支持上传dat文件
- PC端开启"报告授权"时，App可下载完整的"双百分报告"

### 核心交互设计

#### 设备绑定流程
- PC端选择用户→点击"绑定"→从下拉列表选择可用设备号→设置绑定周期（默认5天）→确定绑定
- **限制**：设备号不可手动输入，仅能从可用列表选择；若无可选设备，需先解绑原用户

#### 实时监测数据流
- 用户穿戴设备→App采集生理信号→上传至云服务器→PC端订阅实时流→展示动态波形
- 要求App端保持网络连接且已点击"开始睡眠"，否则PC端无法获取实时数据

#### 历史数据回放（PC端）
- 缩放：鼠标滚轮前推/后拉，放大/缩小时间轴
- 拖选：按住左键拖动选择时间段，右键可"还原缩放"
- 播放：在选中区域点击播放按钮，从该点开始回放
- 量尺：左键点击两点，自动计算时间差（用于测量呼吸暂停时长等）
- 波形增强：滚动滚轮可局部放大心电/呼吸波幅

### 系统设计特点
- 多用户隔离：通过"用户-设备"绑定机制，确保5人系统数据互不干扰
- 流程标准化：用户注册四步法、设备绑定强校验、报告生成双因子（AI+问卷）
- 专业级回放：提供科研级数据浏览工具
- 软硬一体交付：专用电脑预装软件，降低部署复杂度
- 扩展性设计：支持外接血氧戒指，未来可接入更多生理传感器

### 使用流程
1. 初始设置：管理员创建机构→添加设备→创建管理师→用户下载App并绑定
2. 日常使用：用户选择测评→完成测评→查看报告→管理师查看数据
3. 数据管理：异常数据手动上传→管理师定期分析→必要时调整设备分配

### 兼容性与性能要求
- PC软件：兼容Windows主流版本
- 后台管理系统：兼容主流浏览器
- 设备连接响应时间≤3秒
- 大数据量查询响应时间≤5秒
- 系统可用性≥99.5%

### 安全性要求
- 用户健康数据加密存储
- 传输过程使用HTTPS协议
- 严格的权限控制机制，确保数据隐私
