# 睡眠呼吸监测系统详细设计说明

## 一、系统概述

LIFETIDE® BBS 睡眠呼吸监测仪（五人系统）是一套面向医疗机构或健康管理机构的**多用户睡眠呼吸障碍筛查与评估解决方案**。系统以非侵入式传感技术为核心，结合移动终端、云平台与 PC 管理端，实现从设备分配、用户注册、睡眠监测到报告生成的全流程闭环管理，支持最多 **5 名用户并行使用**。

系统采用“端-边-云”协同架构，兼顾数据实时性、操作便捷性与专业分析深度，适用于睡眠门诊、体检中心、康养机构等场景。

---

## 二、系统组成

本系统由以下六大核心组件构成：

| 组件 | 功能说明 |
| --- | --- |
| **1. 传感发射器（设备）** | 集成心电、呼吸、体位传感器，实时采集生理信号并通过蓝牙/WiFi传输；每台设备具唯一设备号。 |
| **2. 收纳盒与电极** | 用于设备存储、充电及信号采集（电极贴附于用户胸部）。 |
| **3. 移动终端（App）** | 用户端操作入口，运行于 PAD 或手机，负责设备连接、开始睡眠、数据上传及查看个人报告。 |
| **4. 云服务器** | 承担用户认证、数据存储、AI 分析、报告生成与多端同步。 |
| **5. 多 PC 终端（BBS-LTSP 软件）** | 医生/健康管理师专用工具，用于用户管理、设备调度、实时监测与历史数据回放。 |
| **6. 专用电脑** | 预装 BBS-LTSP 软件，桌面提供快捷方式，保障操作环境一致性。 |

> ✅ 系统出厂即完成软硬件集成，开箱即用。

## 三、软件架构与功能模块

### （一）PC 端软件：BBS-LTSP（版本未标注）

#### 1. 登录认证

*   双击桌面快捷方式启动；
    
*   输入用户名/密码登录（支持“记住密码”）；
    
*   依赖网络环境：局域网 ≥100M，互联网 ≥10M。
    

#### 2. 用户管理模块

*   **用户注册（四步流程）**：
    
    1.  手机验证（短信验证码）
        
    2.  基本信息（姓名、性别、年龄等）
        
    3.  身体状况（身高、体重、病史等）
        
    4.  信息完善（紧急联系人等）
        
*   **用户查询与维护**：
    
    *   支持修改、删除用户信息；
        
    *   已删除用户可通过“右上角找回”恢复；
        
    *   查看用户绑定的设备状态。
        

#### 3. 设备管理模块

*   **子账号设备管理**：预分配各子账号可使用的设备范围（安装时配置，通常无需修改）；
    
*   **设备查询**：
    
    *   查看设备使用状态（空闲/已绑定/异常）；
        
    *   设备异常时可直接在页面提交报修。
        

#### 4. 睡眠管理模块

*   **实时监测**：
    
    *   查看当前正在监测用户的实时心电、呼吸、体位波形；
        
    *   前提：用户 PAD 已联网且点击了 App 中的【开始睡眠】。
        
*   **历史查询**：
    
    *   支持按 **姓名、手机号、设备号、日期** 模糊检索；
        
    *   可回放完整睡眠过程的原始生理数据；
        
    *   支持多维度缩放、拖选、播放控制（见下文交互设计）。
        

#### 5. 报告生成与导出

*   测评结束后，系统基于：
    
    *   用户填写的**自评问卷**
        
    *   AI 对生理数据的**自动分析**
        
    *   生成 **“双百分睡眠报告”**（含客观指标与主观评分）；
        
*   在“历史查询”中找到用户，点击“查看”进入报告页；
    
*   点击左上角 **导出图标** → 选择 **PDF 格式** → 自定义文件名（如“张三20240716睡眠报告”）保存。
    

---

### （二）移动端 App（配套 PAD 使用）

*   **首次使用**：输入 PC 端已绑定的设备号完成配对；
    
*   **连接成功**：界面显示稳定心电图；
    
*   **开始睡眠**：点击【开始睡眠】按钮，启动监测；
    
*   **扩展设备**：支持通过左上角菜单扫描连接**血氧戒指**，提升血氧饱和度监测精度；
    
*   **报告查看**：测评完成后，在【菜单 > 个人报告】中查看；
    
*   **PC 报告授权**：当 PC 端开启“报告授权”，App 可下载完整的“双百分报告”。

## 四、核心交互与数据流设计

### 1. 设备绑定流程（关键约束）

```mermaid
graph LR
A[PC端选择用户] --> B[点击“绑定”]
B --> C[从下拉列表选择可用设备号]
C --> D[设置绑定周期 默认5天]
D --> E[确定绑定]
E --> F[设备状态更新为“已占用”]
```
> ⚠️ **限制**：设备号不可手动输入，仅能从可用列表选择；若无可选设备，需先解绑原用户。

### 2. 实时监测数据流

```plaintext
用户穿戴设备 → App 采集生理信号 → 上传至云服务器 → PC 端订阅实时流 → 展示动态波形

```
> 要求 App 端保持网络连接且已点击“开始睡眠”，否则 PC 端无法获取实时数据。

### 3. 历史数据回放交互设计（PC 端）

*   **缩放**：鼠标滚轮前推/后拉，放大/缩小时间轴；
    
*   **拖选**：按住左键拖动选择时间段，右键可“还原缩放”；
    
*   **播放**：在选中区域任意点点击 ▶ 播放按钮，从该点开始回放；
    
*   **量尺**：左键点击两点，自动计算时间差（用于测量呼吸暂停时长、心律不齐间隔）；
    
*   **波形增强**：在拖动状态下，滚动滚轮可局部放大心电/呼吸波幅（避开大体动干扰）。

# 使用流程

1.  **初始设置流程**：
    
    *   管理员创建机构账号
        
    *   添加设备并分配给相应机构
        
    *   创建管理师账号
        
    *   用户下载App并绑定设备和管理师（用户用自己手机或是用健康中心提供的已安装APP，已绑定设备的PAD）
        
2.  **日常使用流程**：
    
    *   用户选择相应测评项目
        
    *   按照指引完成测评
        
    *   查看生成的报告
        
    *   管理师通过PC端或后台查看用户数据
        
3.  **数据管理流程**：
    
    *   异常数据需手动上传
        
    *   管理师定期查看和分析用户数据
        
    *   必要时调整设备分配或用户分组
